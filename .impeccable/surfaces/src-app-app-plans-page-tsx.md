# Plans and memories continuity

- **Mode:** Operate
- **Audience/job:** An active couple member schedules a shared experience, marks it complete, and preserves it as a memory without losing provenance.
- **Direction:** Extend the verified Shared-Journal Thread. Plans use the timeline as temporal structure; memories loosen into a bounded story gallery. Deep wine remains action, quiet blush explains context and privacy, and content—not metrics—carries hierarchy.
- **Memorable moment:** A completed plan changes from an operational entry into a clear “Save this memory” bridge, then the resulting memory names the plan it came from.
- **Constraints:** Mobile-first dedicated creation routes; exact timezone language; explicit couple boundary; bounded queries; no fake checklist, reminder, calendar, or media controls before their services and tests exist.
- **Unresolved:** Month/week calendar composition, attachment workflow, signed media viewer, derivatives, checklist/reorder interaction, and reminder delivery.
